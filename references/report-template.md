## Markdown 报告结构

```markdown

## 二、关键指标

> 每个指标的口径卡见 `caliber-cards.md`

| 指标名 | 值 | 单位 | 环比 | 口径说明 |

## Excel 报表结构

| Sheet | 内容 |
|---|---|
| 原始数据 | 清洗后的源版数据（列名中文+类型标注） |
| 统计数据 | 分组统计表 + 描述统计矩阵 |
| 图表 | XlsxWriter 原生图表（柱/折/饼） |
| 口径卡 | 每个指标的分子/分母/过滤条件确认记录 |

## 颜色约定（借鉴 Anthropic xlsx skill）

| 用途 | 颜色 |
|---|---|
| 可编辑输入/假设 | 蓝色字体 (0,0,255) |
| 公式 | 黑色 |
| 跨表引用 | 绿色 (0,128,0) |
| 跨文件引用 | 红色 (255,0,0) |
| 关键假设/待填 | 黄色底色 (255,255,0) |

## 九问检查单（交付前必跑，借鉴 DMB Step 8）

| # | 检查项 |
|---|---|
| 1 | 主键 — 所有清洗后的表都有主键吗？ |
| 2 | 去冗余 — 有没有没用上的中间表？ |
| 3 | 延期事项 — 有没有"以后再说"的问题？ |
| 4 | 可见性 — 输出文件在 output/ 目录能查到吗？ |
| 5 | 脚本 — 脚本能正常运行吗？ |
| 6 | 资产血缘 — 数据来源→清洗步骤→口径→输出，理清了吗？ |
| 7 | 口径卡 — 口径卡全部填完且用户确认了吗？ |
| 8 | 数据质量 — 探源六项结果在报告里体现了吗？ |
| 9 | 用户实测 — 用户亲自点过输出物了吗？ |

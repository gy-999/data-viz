## 常见对话模式

### 模式 1："帮我看看这些数据"

```
用户: "帮我看一下 D:\数据 里有什么"
AI:
  【扫描完成】
  目录: D:\数据
  发现: 35 个文件 / 2.29 GB
  
  | 类型 | 数量 | 说明 |
  |---|---|---|
  | .sql（INSERT 脚本） | 7 个 | 含 600MB 大文件 |
  | .CSV.GZ（压缩分片） | 18 个 | ZJsftp 目录下的 WELL/ODF 数据 |
  | .csv | 1 个 | 225MB |
  | .tsv | 1 个 | 41MB |
  | .xlsx | 1 个 | 75KB |
  
  你想从哪里开始看？
```

### 模式 2："分析这个文件"

```
用户: "分析一下这个 Excel"
AI: 已读取完成，请告诉我你最关心的 2-3 个问题，
     我会根据这个选择图表类型和分析维度。
```

### 模式 3："对比两份数据"

```
用户: "对比这两个表的 sa_label 数据"
AI: 【交叉分析】
  | 字段 | 表 A | 表 B | 差异 |
  |---|---|---|---|
  | 行数 | 1,448,751 | 14 | 表 B 明显较少 |
  | 字段 | 17 | 10 | 表 B 缺少 7 个字段 |
  
  我有以下发现：
  [找出同名不同义的字段、孤儿记录、结构差异]
```

## 口径确认对话范例

> AI 拿真实数据举例，用户边答边把口径精确化

```
AI: sa_label 表里有 1,448,751 条记录，其中 48.6%（约 70 万）
     的 label_status 是 'created'（已创建但未使用）。这些算不算？
用户: 先不算，我们只看 'active' 和 'archived' 的。
AI: 好。那金额字段有 28.4% 是空字符串 ''，
     这些空字符串的记录在算指标时应该怎么处理？算 0 还是排除？
用户: 空字符串表示"还没有赋值"…… 排除吧，不算 0。
```

## 错误处理

| 场景 | AI 行为 |
|---|---|
| 文件不存在 | 提示路径检查 + 建议备选路径 |
| 编码错误 | 自动切换编码重新尝试（utf-8-sig → gbk → gb18030） |
| 数据库连不上 | 检查连接信息 + 密码是否正确 |
| 数据量过大 | 走抽样预览，标注"基于抽样" |
| SQL 语法不兼容 | 自动适配 MySQL/PG/SQLite |

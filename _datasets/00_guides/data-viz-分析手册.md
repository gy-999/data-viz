# data-viz 分析手册

**AI 直读式数据分析工作流 · 使用说明与实测报告**

版本：v3.0（AI 直读 + 用户选单 + 统计分析扩展）
分析工具：data-viz Skill（数据分析 Agent Skill）
数据范围：8 条通路实训数据集 + 本机媒体资产
文档定位：可直接用于对外演示与分析交接

---

## 摘要

本手册说明一套 AI 直读式数据分析工作流的使用方法，并附本次在真实数据上的完整实测结果。

工作流的核心主张是：**分析师的判断由 AI 亲自完成，代码只承担两类机械工作**——产出可视化看板与交付报告、抽取文档类资产。据此，本手册给出可直接照做的五个步骤、23 种图表的能力清单、以及一次端到端分析的全部结论。

实测在中文 GBK 订单数据（4,000 行 × 12 列）上完成，覆盖编码识别、数据质量诊断、口径定义、看板生成、质量闸门与 Word 总结报告六个环节，全部通过；过程中发现并修复了渲染引擎一处会导致数值静默归零的缺陷。

## 一、它是什么

`data-viz` 是一个**数据分析 Agent Skill**。它不是一套预设脚本管线，而是「给 AI 的分析规范 + 一个可调用的工具箱」。

| 组成 | 内容 |
|---|---|
| 分析规范 | 何时触发、怎么读数据、探源查什么、口径怎么定、输出出什么 |
| 工具箱 | 看板渲染引擎、质量闸门、报告排版、媒体盘点、文档抽取、SQL 解析 |
| 方法论 | 图表选型规则、数据质量规则、报告模板、交互指南 |

**核心主张**：AI 就是分析师。执行等于推理，而不是调用预写管线。

**能力边界（明确定义）**
- 会做：数据分析、统计、可视化、数据整理、清洗、出报告、生成看板、数据质量诊断、资产盘点、目录扫描、多源合并、大文件自适应、SQL 脚本解析、MySQL 直连
- 不做：建数仓、写 SQL 建表、机器学习建模、代码审查

**触发方式**：说人话即可。例如「帮我看看这些数据」「盘点这个目录有没有重复图片」「出个能发群里的看板」。

## 五、工作流程（五个步骤）

| 步骤 | 谁执行 | 内容 | 产出 |
|---|---|---|---|
| 1. AI 直读 | **AI** | 按编码级联（utf-8-sig → utf-8 → gbk → gb18030）读入数据，逐列查看真实值 | 对数据的直接认识 |
| 2. 探源六项 | **AI** | 空值率（空串也算空）、哨兵值、枚举越界、重复行、时间悬崖、孤儿外键；发现异常即用真实数据提问 | 数据质量结论 |
| 3. 口径拍板 | **AI 提问 + 你拍板** | 你口述指标含义 → AI 用真实数据举例确认 → 沉淀口径卡（分子/分母/只算/不算/更新周期） | 口径卡 |
| 4. 输出选单 | **你选择** | 从分析意图菜单与交付物菜单中选定 | `plan.json` |
| 5. 代码登场 | 工具 | 生成看板 → 过质量闸门 → 出 Word 总结报告 | 看板 + 报告 + 口径卡 |

**判断标准**：需要判断的环节交给 AI，纯机械搬运交给脚本。因此「读数据、探源、定口径」由 AI 亲自完成；「渲染、排版、闸门、文档抽取」由代码执行。

**质量闸门（硬拦截）**：展示字段必须有中文业务名、数仓表名必须符合 `ads_*` / `dwd_*` 约定、图表选型必须匹配数据形态——不通过直接拒绝出图。

## 六、分析能力清单

### 6.1 图表类型（23 种）

| 类别 | 类型 |
|---|---|
| 指标与文本 | KPI 卡（悬停显示口径）、文本块、标题 |
| 趋势与构成 | 折线、面积堆叠、柱状、饼图、直方图 |
| 关系与流向 | 散点、热力矩阵、漏斗、桑基、瀑布 |
| 对比与目标 | 雷达、仪表盘、子弹图、明细表 |
| **统计分析（新增）** | **箱线图、正态 Q-Q、帕累托、缺失值画像、相关矩阵、回归** |

### 6.2 统计分析能力

| 分析 | 方法 | 输出 |
|---|---|---|
| 分布对比 | 四分位（线性插值）+ 1.5×IQR 离群点栅栏 | 中位数、Q1/Q3、均值、标准差、变异系数、离群点 |
| 正态性 | 秩概率 + Acklam 正态分位数逼近（误差 < 1.15e-9） | Q-Q 散点、参考线、偏度、峰度 |
| 关键少数 | 降序累计占比 | 累计曲线、80% 分界、关键少数项数 |
| 数据质量 | 分字段缺失率 + 分维度缺失率 | 双栏缺失率对比 |
| 相关性 | 皮尔逊 / 斯皮尔曼（平均秩处理并列值） | 相关矩阵、最大相关对 |
| 回归 | 最小二乘 | 斜率、截距、R² |

> 全部统计量由引擎本地计算，不引入 scipy 依赖。

### 6.3 看板交互

单文件离线网页（图表库已内嵌），包含：KPI 卡口径悬停（看分子/分母）、图表点击 L2 下钻、再点 L3 到逐条明细、码值字典表（把 `1/2/3` 翻译为业务中文）、响应式布局。无需联网、无需安装软件，双击即可打开，可直接通过微信或邮件转发。

## 七、实测案例：中文订单数据完整分析

### 7.1 数据概况

| 项目 | 值 |
|---|---|
| 文件 | `chinese_orders_gbk.csv` |
| 规模 | 4,000 行 × 12 列（中文表头） |
| 编码 | GBK（UTF-8 解码失败） |
| 字段 | 订单号、订单日期、客户、客户类型、城市、省份、产品类别、产品名称、销售额、数量、折扣、利润 |

### 7.2 探源结论（第 1–2 步）

| 检查项 | 实测结果 | 含义与处理 |
|---|---|---|
| 编码 | utf-8-sig / utf-8 解码失败，GBK 成功 | 源系统为 GBK 环境，读取必须级联回退 |
| 空值（伪装） | 客户 291 行、客户类型 168 行为空字符串 | 空串不是 NULL，按缺失处理 |
| 缺失（字面） | 折扣列 1,047 行为字面 `None` | 伪装的缺失值，直接计算会得出错误结果 |
| 主键重复 | 订单号重复 2,075 行（唯一 1,925 / 共 4,000） | 同一订单含多个商品行属正常；**订单数必须去重** |
| 时间维度 | 1,243 行（31%）日期为 2024-03-15，另有 2018 年 `M/D/YYYY` 格式混存 | 日期被压平且格式不一致 → **月度趋势不可解释** |
| 数值分布 | 利润 716 行为负（区间 -3,840 ~ 3,920） | 存在亏损与极端值，用分位数与箱线图描述 |

### 7.3 口径定义（第 3 步）

| 指标 | 分子 | 分母 | 说明 |
|---|---|---|---|
| 销售额合计 | 全部 4,000 行销售额之和 | 无（总量指标） | 折扣为空的行按标价计入 |
| 订单行数 | 原始数据行数 | 无 | 不做去重 |
| 订单数 | 订单号去重计数 | 无 | 与「订单行数」并列展示 |
| 客户数 | 客户字段去重 | 无 | 空串 291 行不计入 |
| 亏损订单行 | 利润 < 0 的行数 | 全部 4,000 行 | 利润为空不计入分子 |

### 7.4 核心结果

| 指标 | 值 |
|---|---|
| 销售额合计 | **923,303 元** |
| 订单行数 | 4,000 行 |
| 订单数（去重） | 1,925 笔 |
| 客户数 | 860 人 |
| 亏损订单行 | 716 行（17.9%） |

**产品类别构成**：技术类 347,778 元（37.7%）、家具 293,001 元（31.7%）、办公用品 282,524 元（30.6%）——三类较为均衡。

**省份分布与帕累托**：四川省 322,285 元居首，前 4 个省份累计即达 80%（关键少数），其余省份合计约 20%，呈明显长尾。

**折扣与利润**：斯皮尔曼相关系数 **-0.53**，为全部变量对中最强相关。同时「无折扣」档贡献销售额最高（311,948 元）——高折扣并未换来销售额领先。

**回归分析**：利润 ~ 销售额，斜率 0.053、R² 仅 **0.0196**。销售额几乎无法解释利润，成本与折扣结构对利润的支配作用远大于营收规模。

**利润分布**：偏度 -0.38、峰度 165，严重右偏且尖峰——绝大多数订单利润接近零附近，少数订单贡献极端值，**均值会失真**。

**缺失画像**：折扣列缺失率 26.2%（1,047 行），客户列 7.3%，客户类型 4.2%；按产品类别分组缺失率均在 2.9% 左右，说明缺失集中在字段层面而非某类产品。

### 7.5 分析结论

1. **数据可用性受限**：时间维度因日期压平与格式混存不可用；折扣字段缺失四分之一。在修复前，任何时间趋势类与折扣力度类结论均不成立。
2. **结构均衡**：产品类别三分天下，无单极依赖。
3. **地域高度集中**：前 4 个省份占 80% 销售额，资源投放应优先覆盖。
4. **折扣策略需复盘**：折扣与利润显著负相关，且深度折扣未带来销售额优势。
5. **利润不可用均值衡量**：分布严重偏态，应改用中位数与分位数体系汇报。

## 八、新增六种统计图的适用场景

| 图表 | 回答什么问题 | 何时用 | 关键输出 |
|---|---|---|---|
| 箱线图 | 各组分布差异有多大？有没有异常值？ | 按类别比较数值分布 | 中位数、四分位、离群点、变异系数 |
| 正态 Q-Q | 这列数据近似正态吗？ | 决定用均值还是中位数 | 偏度、峰度、Q-Q 偏离形态 |
| 帕累托 | 哪几个类别贡献了大部分？ | 找「关键少数」、定优先级 | 累计占比曲线、80% 分界项 |
| 缺失值画像 | 哪些字段缺失严重？是否集中在某类？ | 出结论前的数据质量把关 | 分字段缺失率 + 分维度缺失率 |
| 相关矩阵 | 哪些变量互相关联？ | 找驱动力、筛特征 | 相关系数矩阵、最强相关对 |
| 回归分析 | 一个变量能解释另一个多少？ | 量化关系强度与方向 | 斜率、截距、R² |
